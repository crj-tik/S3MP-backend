## 2. 配额领域与服务层

- [x] 2.1 将配额范围统一为 `tenant`、`application`、`storage_space`，同步领域枚举、目录元数据、请求校验和响应模型。
- [x] 2.2 实现租户与应用/存储空间配额的稳定父子关联校验，拒绝跨租户、已删除父级和超出上层可分配容量的配置。
- [x] 2.3 实现删除账本调整服务：按固定 UUID 顺序锁定关联配额，按文件实际大小一次性扣减 `used_bytes`，并记录幂等调整结果。
- [x] 2.4 实现 reservation 回收服务，覆盖过期、失败、取消、已提交、缺失关联和重复执行场景。
- [x] 2.5 为配额查询增加统计一致性状态、测量时间、最近对账运行标识和差异摘要，并保证 `available_bytes` 计算不出现负数或伪一致。

## 3. 文件删除与入库关联

- [x] 3.1 将成功删除从直接物理删除记录调整为带保留期的不可用终态，保证普通文件查询、下载和授权接口排除该终态。
- [x] 3.2 将 provider 删除成功、文件终态转换、配额扣减和审计事件纳入可重试的数据库事务边界。
- [x] 3.3 确保 provider 删除失败、授权失效、目标版本不一致和 Worker 重试不会提前或重复释放配额。
- [x] 3.4 将入库记录、文件对象、reservation、删除结果和配额调整关联到同一 provenance 查询链，并脱敏公开响应。
- [x] 3.5 为终态保留清理增加 retention 任务，清理前确认账本已调整且不会再次触发扣减。

## 4. 共享 S3 对账

- [x] 4.1 扩展对象存储端口和适配器，支持按平台 Bucket、服务端派生命名空间和 continuation token 分页列举对象及必要元数据。
- [x] 4.2 实现数据库文件投影与 S3 清单的匹配器，分类 matched、provider_missing、db_missing、size_mismatch、duplicate_mapping 和 orphan_object。
- [x] 4.3 实现按租户、应用和存储空间范围的 dry-run 对账报告，报告计算使用量、记录使用量、差异、孤儿对象和无法确认归属对象。
